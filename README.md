# Monster Truck of Hell

A Bloxity remake of the Roblox game: race your monster truck over hellish platforms above a lava sea.

- `monster-truck-of-hell-client/` – three.js + React web client
- `monster-truck-of-hell-server/` – Colyseus game server

TAGS: Monster Truck, Racing, Fun, Parkour, Obby, Driving, Offroad, Speedrun, Physics, Extreme Sports
