# Monster Truck of Hell – server

Colyseus room (`monster_truck_hell`) with the 8-minute race clock (x2 once someone finishes),
server-checked course progress, Cash / XP / levels, trucks, hats, powers, the Daily Wheel and
Bloxity Gems purchases (webhook at `/webhooks/legion`).

```
npm install
cp .env.example .env
npm run dev
```
