# Monster Truck of Hell – client

3D web client (three.js + React, Vite) for the Bloxity platform.

🔥 Race your MONSTER TRUCK to the finish line to claim victory!
🚧 Jump across platforms and dodge obstacles along the way!
🛠️ Unlock incredible upgrades and personalize your truck for ultimate domination!

## Run

```
npm install
cp .env.example .env   # local server: VITE_SERVER_URL=ws://localhost:2567
npm run dev
```

Controls: W/S gas & brake · A/D steer · Space jump · Q nitro · Shift drift · E interact · drag to look around.
